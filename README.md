# Urgente! — site-livro

Versão pública e estática de **Urgente! Chamada de Emergência para o Fim do Mundo**.

O conteúdo publicado fica em `public/`. Cada push para `main` aciona a publicação automática no GitHub Pages.

Este repositório contém somente os arquivos necessários para servir o site. Manuscrito, imagens-mestre, capturas de QA e ferramentas editoriais permanecem no repositório de produção.
